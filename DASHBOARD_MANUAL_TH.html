ChildRegistry • คู่มือแยกสำหรับผู้ตรวจและผู้รับผิดชอบโครงการ

ฉบับปรับปรุง 30 กันยายน 2569 • อ้างอิง ChildRegistry 1.0.1

คู่มือนี้ใช้กับโปรแกรมชุดฟันน้ำนมปัจจุบัน ซึ่งมีเกณฑ์อายุต่ำกว่า 3 ปีและตั้งแต่ 3 ปีขึ้นไป ไม่ใช่แอปฟันแท้สำหรับเด็กอายุ 6–12 ปีที่วางแผนไว้แยกต่างหาก ตัวเลขในตัวอย่างเป็นข้อมูลสมมติเพื่ออธิบายวิธีอ่านผล

1. จะใช้หน้าใดตอบคำถามอะไร

คำถามที่ต้องการตอบหน้าที่ใช้
เด็กแต่ละคนดีขึ้นหรือแย่ลงจากการตรวจครั้งแรกเพียงใดDashboard เลือก ครั้งแรก → ล่าสุด
หลังจากตรวจครั้งก่อน เด็กเปลี่ยนแปลงอย่างไรDashboard เลือก ครั้งก่อน → ล่าสุด
เด็กคนใดต้องติดตามเป็นพิเศษคลิกช่อง แย่ลง / ยังเสี่ยง ในตารางสถิติ แล้วคลิกชื่อเด็ก
โรงเรียนมีแนวโน้มดีขึ้นจากรอบ 1 ไป 3 หรือไม่กราฟเปรียบเทียบรอบตรวจ เลือกคู่รอบและโรงเรียน
พฤติกรรมหมวดใดควรปรับปรุงกราฟรายหมวด และตารางสถิติรายรายการ
ต้องการรายงานข้อมูลดิบที่กรองไว้ดูเด็กทั้งหมด (Records) → กรอง → ส่งออก Excel

แนวทางเริ่มต้น: ดูภาพรวม → เลือกประเด็นที่ยังเป็นปัญหา → ดูรายชื่อ → ตรวจรายละเอียดรายคน → วางแผนติดตาม → ตรวจซ้ำด้วยเงื่อนไขเดิม

2. เตรียมข้อมูลก่อนวิเคราะห์

  • 1. ตรวจพาธฐานข้อมูลด้านบนหน้าหลักให้ถูกไฟล์
  • 2. บันทึกข้อมูลให้สำเร็จก่อนเปิด Dashboard ข้อมูลที่ยังกรอกค้างอยู่จะไม่ถูกนำมาวิเคราะห์
  • 3. เด็กคนเดิมต้องใช้ CID เดิมทุกครั้ง และมีรอบตรวจแยกกันอย่างชัดเจน
  • 4. ตรวจวันเกิดและวันที่ตรวจให้ถูกต้อง โดยวันที่รอบปลายทางต้องหลังรอบต้นทาง
  • 5. ตรวจชื่อโรงเรียนให้สะกดเหมือนกัน ไม่แยกเป็นหลายชื่อจากช่องว่างหรือคำย่อ
  • 6. เปิด Records เพื่อตรวจรอบซ้ำ ข้อมูลขาด และค่าที่บันทึกผิดก่อนสรุปผล

Dashboard อ่านข้อมูลล่าสุดเมื่อเปิดหน้า หากแก้ไขหรือบันทึกเพิ่ม ให้ปิดแล้วเปิด Dashboard ใหม่เพื่ออ่านข้อมูลชุดใหม่ การเปิดกราฟและ Dashboard ไม่แก้คะแนนหรือเขียนข้อมูลย้อนหลัง

เด็กที่ตรวจเพียงครั้งเดียวมีประโยชน์ต่อการดูความครอบคลุม แต่ยังไม่สามารถสรุปการเปลี่ยนแปลงก่อน–หลังได้

3. เปิดและตั้งค่า Dashboard

  • 1. จากหน้าหลักกด “ติดตามผล / Dashboard”
  • 2. เลือกทุกโรงเรียนหรือโรงเรียนที่สนใจ ในหน้านี้ใช้โรงเรียนจากการตรวจล่าสุดของเด็ก
  • 3. เลือกคู่เปรียบเทียบตามวัตถุประสงค์
  • 4. อ่านจำนวนเด็กและจำนวนที่เปรียบเทียบได้ก่อนอ่านร้อยละ
ตัวเลือกคู่ที่โปรแกรมใช้เหมาะกับงาน
ครั้งแรก → ล่าสุดครั้งแรกและครั้งล่าสุด เรียงตามวันที่ตรวจติดตามการเปลี่ยนแปลงตลอดโครงการ
ครั้งก่อน → ล่าสุดสองครั้งสุดท้าย เรียงตามวันที่ตรวจติดตามการเปลี่ยนแปลงช่วงล่าสุด

ตัวอย่าง เด็กมีรอบ 1, 2, 3 ตามลำดับวันที่: แบบแรกเปรียบเทียบ 1 → 3 ส่วนแบบครั้งก่อนเปรียบเทียบ 2 → 3 ถ้าเด็กมีสองครั้ง ทั้งสองตัวเลือกจะใช้คู่เดียวกัน หากต้องการคู่รอบที่ระบุเอง ให้เปิด “กราฟเปรียบเทียบรอบตรวจ”

ช่อง “ค้นหาเด็ก: ชื่อ / CID” กรองเฉพาะรายชื่อเด็กในส่วนล่างของ Dashboard ไม่ได้เปลี่ยนตัวเลขภาพรวมด้านบน และค้นหาภายในกลุ่มรายชื่อที่กำลังเปิดจากช่องสถิติด้วย

4. อ่านแถบสรุปและไอคอนด้านบน

แถบสรุปแสดงจำนวนเด็ก ตรวจครั้งเดียว มีหลายครั้ง เทียบระดับความเสี่ยงได้ และผลต่างคะแนนโดยเฉลี่ย/มัธยฐาน

ไอคอนสี่กลุ่มด้านบนสรุปการเปลี่ยน “ระดับความเสี่ยงรวม” ไม่ใช่จำนวนเด็กที่ดีขึ้นในคำถามใดก็ได้

สถานะความหมายของระดับความเสี่ยงรวมตัวอย่าง
ดีขึ้นระดับล่าสุดต่ำลงสูงมาก → สูง หรือ สูง → ต่ำ
แย่ลงระดับล่าสุดสูงขึ้นต่ำ → สูง หรือ สูง → สูงมาก
คงผลดีทั้งสองครั้งเป็นระดับต่ำต่ำ → ต่ำ
ยังเสี่ยงอยู่ระดับสูงเท่าเดิมหรือสูงมากเท่าเดิมสูง → สูง หรือ สูงมาก → สูงมาก
เปรียบเทียบไม่ได้ข้อมูลหรือเกณฑ์ไม่พร้อมเทียบตรวจครั้งเดียว หรือข้ามเกณฑ์อายุ

“ยังเสี่ยง” ไม่ได้แปลว่าคะแนนเท่าเดิมเสมอไป เช่น คะแนน 10 ลดเป็น 7 แต่ยังอยู่ระดับสูงมากทั้งคู่ จึงยังแสดงว่า “ยังเสี่ยง” ในการเทียบระดับ แม้คะแนนลดลงแล้ว

5. อ่านตารางระดับความเสี่ยง 3 × 3

หัวแถวคือระดับก่อน ส่วนหัวคอลัมน์คือระดับล่าสุด ช่องตัดกันคือจำนวนเด็กที่เปลี่ยนจากระดับนั้นไปอีกระดับหนึ่ง

ก่อน / ล่าสุดต่ำสูงสูงมาก
ต่ำคงผลดีแย่ลงแย่ลง
สูงดีขึ้นยังเสี่ยงแย่ลง
สูงมากดีขึ้นดีขึ้นยังเสี่ยง

ตัวอย่าง ช่องแถว “ก่อน: สูงมาก” และคอลัมน์ “ล่าสุด: ต่ำ” ขึ้น 5 คน หมายถึงมีเด็ก 5 คนลดจากสูงมากเป็นต่ำ คลิกช่องนั้นเพื่อดูรายชื่อด้านล่าง แล้วคลิกชื่อเพื่อดูรายละเอียด

ควรดูทั้งกลุ่มที่ดีขึ้นและกลุ่มที่แย่ลง เพราะจำนวนรวมที่ดูดีขึ้นอาจยังมีเด็กบางกลุ่มต้องติดตาม

6. อ่านคะแนนเปลี่ยนแปลง ค่าเฉลี่ย และมัธยฐาน

คะแนนเปลี่ยนแปลง = คะแนนปลายทาง − คะแนนต้นทาง

ผลต่างความหมาย
ติดลบ เช่น −3คะแนนลดลง 3 คะแนน
0คะแนนเท่าเดิม
บวก เช่น +2คะแนนเพิ่มขึ้น 2 คะแนน

คะแนนต้นทางเป็นครั้งแรกหรือครั้งก่อนตามโหมดที่เลือก แม้ข้อความสรุปบางตำแหน่งใช้คำว่า “ก่อนหน้า” ให้ตรวจตัวเลือกคู่เปรียบเทียบประกอบ

ค่าเฉลี่ยคือผลต่างคะแนนรวมแบ่งด้วยจำนวนเด็กที่มีคะแนนเปรียบเทียบได้ ส่วนมัธยฐานคือค่ากลางเมื่อเรียงผลต่างจากน้อยไปมาก ใช้ดูแนวโน้มประกอบกัน

ตัวอย่าง ผลต่างของเด็ก 5 คนเป็น −6, −2, −1, 0, +4 จะได้ค่าเฉลี่ย −1 และมัธยฐาน −1 คะแนน แม้ภาพรวมลดลง ยังมีเด็กหนึ่งคนคะแนนเพิ่ม 4 คะแนน จึงควรเปิดดูรายคนด้วย

ค่า n ข้างคะแนนคือจำนวนเด็กที่ใช้คำนวณคะแนน อาจต่างจากจำนวนที่เทียบระดับความเสี่ยงได้หรือจำนวนที่เทียบพฤติกรรมรายข้อได้

7. อ่านตารางสถิติรายรายการจาก AlertValue

AlertValue ใน Codebook ระบุค่าที่ถือว่าเสี่ยงสำหรับรายการนั้น โปรแกรมตรวจค่าก่อนและหลังว่าเข้าเกณฑ์เสี่ยงหรือไม่ แล้วจัดสถานะ

ก่อนหลังสถานะ
เสี่ยงไม่เสี่ยงดีขึ้น
ไม่เสี่ยงเสี่ยงแย่ลง
ไม่เสี่ยงไม่เสี่ยงคงผลดี
เสี่ยงเสี่ยงยังเสี่ยง
ข้อมูลใช้เทียบไม่ได้อย่างน้อยหนึ่งครั้ง—เปรียบเทียบไม่ได้

รหัสคำตอบไม่ใช่คะแนนที่นำมาลบกันได้ทุกข้อ และเลขน้อยไม่ได้หมายถึงดีเสมอไป ต้องอ่านความหมายรหัสและ AlertValue ของข้อนั้น เช่น เปลี่ยนจากค่าเสี่ยงหนึ่งไปอีกค่าเสี่ยงหนึ่งยังจัดเป็น “ยังเสี่ยง” แม้ตัวเลขเปลี่ยนแล้ว

รายการที่ไม่มี AlertValue จะไม่ถูกสรุปเป็นตัวชี้วัดเสี่ยง/ไม่เสี่ยง หาก AlertValue ไม่ตรงกับรหัสอนุญาตของคำถาม ข้อนั้นจะเปรียบเทียบไม่ได้ ให้ผู้ดูแลตรวจ Codebook ไม่ควรตีความเป็นผลดี

ตัวหารของร้อยละ

ร้อยละในสี่สถานะแรกใช้เด็กที่เปรียบเทียบข้อนั้นได้เท่านั้น ไม่รวม “เปรียบเทียบไม่ได้”

ตัวอย่างมีเด็กทั้งหมด 25 คน แต่ข้อนี้เปรียบเทียบได้ 20 คน: ดีขึ้น 6 คน แย่ลง 2 คน คงผลดี 8 คน ยังเสี่ยง 4 คน และเปรียบเทียบไม่ได้ 5 คน

ตัวเลขที่แสดงวิธีคำนวณตัวอย่าง
ดีขึ้นดีขึ้น / เปรียบเทียบได้ทั้งหมด6/20 = 30%
แย่ลงแย่ลง / เปรียบเทียบได้ทั้งหมด2/20 = 10%
คงผลดีคงผลดี / เปรียบเทียบได้ทั้งหมด8/20 = 40%
ยังเสี่ยงยังเสี่ยง / เปรียบเทียบได้ทั้งหมด4/20 = 20%
ดีขึ้นในกลุ่มเดิมเสี่ยงดีขึ้น / (ดีขึ้น + ยังเสี่ยง)6/10 = 60%
แย่ลงในกลุ่มเดิมดีแย่ลง / (แย่ลง + คงผลดี)2/10 = 20%

สูตรสองช่องท้ายนี้อ่านตรงตัวได้สำหรับตัวชี้วัดรายข้อแบบเสี่ยง/ไม่เสี่ยง แต่สำหรับแถว “ระดับความเสี่ยงรวม” ซึ่งมีสามระดับ ให้ใช้ตาราง 3 × 3 เป็นหลัก เพราะกลุ่มแย่ลงรวมทั้งต่ำ → สูง และสูง → สูงมาก จึงไม่ควรตีความคำว่า “เดิมดี/เดิมเสี่ยง” ของแถวรวมเหมือนตัวชี้วัดสองสถานะ

หากตัวหารเป็นศูนย์ โปรแกรมแสดง “ไม่มีข้อมูลเปรียบเทียบ” ไม่ใช่ผลดี 0% คลิกช่องดีขึ้น แย่ลง คงผลดี ยังเสี่ยง หรือเปรียบเทียบไม่ได้เพื่อดูเด็กในกลุ่มนั้น ช่องอัตราสองช่องท้ายเปิดรายชื่อกลุ่มดีขึ้นหรือแย่ลง ไม่ใช่รายชื่อทุกคนในตัวหาร

8. ติดตามเด็กเป็นรายบุคคล

  • 1. เลือกโรงเรียนและคู่เปรียบเทียบก่อน
  • 2. คลิกช่องสถิติหรือช่องในตาราง 3 × 3 เพื่อเปิดกลุ่มเด็กที่สนใจ
  • 3. ใช้ชื่อหรือ CID ค้นภายในรายชื่อที่กำลังแสดง
  • 4. คลิกชื่อเด็ก ตารางรายละเอียดจะแสดงประวัติรอบตรวจ วันที่ คะแนน และค่าก่อน–หลังรายข้อ
  • 5. อ่านข้อสังเกตหากโปรแกรมระบุว่าเปรียบเทียบไม่ได้
  • 6. หากสงสัยข้อมูลผิด ให้กลับหน้าหลัก → ดูเด็กทั้งหมด → Edit → บันทึก แล้วเปิด Dashboard ใหม่

ตัวอย่างการติดตาม: เด็กมีระดับความเสี่ยงลดลง แต่พฤติกรรมขนมหวานยังเสี่ยง ให้บันทึกประเด็นติดตามเรื่องขนมหวานไว้ในกระบวนงานของหน่วยงาน แล้วตรวจข้อนี้อีกในรอบถัดไป โปรแกรมรุ่นนี้ยังไม่มีหน้ามอบหมายงานหรือบันทึกแผนติดตามเฉพาะใน Dashboard

หลังคลิกกลุ่มย่อย การล้างคำค้นเพียงอย่างเดียวยังอยู่ในกลุ่มเดิม คลิกชื่อรายการในคอลัมน์แรกของตารางสถิติเพื่อกลับมาดูรายชื่อทั้งหมดตามตัวกรองโรงเรียน

9. เปิดกราฟเปรียบเทียบรอบตรวจ

  • 1. กด “กราฟเปรียบเทียบรอบตรวจ” จากหน้า Dashboard
  • 2. เลือก “จาก” เป็นรอบต้นทาง และ “เทียบกับ” เป็นรอบปลายทาง เช่น รอบ 1 → รอบ 3
  • 3. เลือกโรงเรียน ในหน้านี้อ้างอิงโรงเรียนของรอบปลายทางที่เลือก
  • 4. เลือกกลุ่มอายุ ณ รอบต้นทาง หรือทุกกลุ่มอายุ
  • 5. เลือก “ภาพรวม + ทุกหมวด” เพื่อดูภาพรวมก่อน หรือเลือกหมวดแบบสอบถาม/เกณฑ์ความเสี่ยงที่สนใจ
  • 6. เลือกโหมดกราฟคำตอบทุกรหัสหรือเฉพาะร้อยละที่เสี่ยง
  • 7. เลื่อนลงดูรายการและกด “ดูเด็กที่นำมาเปรียบเทียบ” เพื่อดูรายชื่อ ค่าก่อน ค่าหลัง และสถานะ

กราฟใช้เด็กกลุ่มเดิมที่มีทั้งสองรอบเท่านั้น เช่น รอบ 1 มี 70 คน รอบ 3 มี 20 คน จะไม่ใช้ 70 คนเทียบกับ 20 คนโดยตรง แต่ใช้เด็กที่จับคู่ได้ทั้งสองรอบ ข้อมูลที่ผิดเงื่อนไขจะถูกแยกออกเพิ่มเติมในแต่ละรายการ

ตัวกรองในหน้ากราฟเป็นของหน้านี้เอง ให้ตรวจค่าทุกครั้ง ไม่ควรถือว่าเหมือนตัวเลือกในหน้า Dashboard ก่อนหน้า

10. อ่านแถบสรุปของกราฟ

ข้อความความหมาย
มีข้อมูลทั้งสองรอบจำนวนที่มีรอบต้นทางและปลายทางตามเงื่อนไขที่เลือก
ลำดับวันถูกต้องจำนวนที่ผ่านการตรวจความพร้อมของประวัติและมีวันที่ปลายทางหลังต้นทาง
ข้ามกลุ่มอายุจำนวนคู่ที่อยู่คนละกลุ่มเกณฑ์อายุ
เทียบระดับความเสี่ยงได้จำนวนคู่ที่นำไปเทียบระดับได้จริง
n ของคะแนนจำนวนที่มีผลต่างคะแนนใช้คำนวณได้

หากเลือกกรองกลุ่มอายุ จำนวนที่แสดงเป็นจำนวนหลังกรองกลุ่มอายุนั้นแล้ว รายการที่ข้อมูลอายุหรือประวัติไม่พร้อมอาจไม่อยู่ในกลุ่มที่เลือก

11. อ่านกราฟสองรูปแบบ

คำตอบทุกรหัส (พร้อมสรุปความเสี่ยง)

สำหรับรายการแบบรหัสที่มีตัวชี้วัดใช้ได้ จะแสดงสัดส่วนคำตอบแต่ละรหัสทั้งสองรอบ เช่น ไม่ทำ บางวัน ทุกวัน ช่วยเห็นการเปลี่ยนคำตอบที่กราฟเสี่ยงรวมอาจไม่แสดงให้เห็น

โหมดนี้ไม่ได้เพิ่มกราฟให้ทุกคำถามที่ไม่มี AlertValue และรายการตัวเลขบางชนิดยังแสดงเป็นร้อยละที่เสี่ยง ให้ดูคำอธิบายใต้กราฟแต่ละรายการ

เฉพาะร้อยละที่เสี่ยงตาม AlertValue

มีแท่งต้นทางสีฟ้าและปลายทางสีม่วง แสดงจำนวน/ตัวหารและร้อยละที่ตรงค่าเสี่ยงในเด็กชุดเดียวกัน หากความชุกเสี่ยงลดลง แท่งปลายทางจะสั้นลง

ตัวอย่าง จาก 8/20 คน (40%) เป็น 6/20 คน (30%) หมายถึงลดลง 10 จุดร้อยละ ไม่ใช่ลดลง 10% แบบสัมพัทธ์ ในกรณีนี้การลดแบบสัมพัทธ์เท่ากับ 25% แต่หน้าจอรายงานเป็น “จุดร้อยละ”

จำนวนเสี่ยงสุทธิลดลง 2 คนไม่ได้แปลว่ามีเด็กดีขึ้นเพียง 2 คนเสมอไป อาจดีขึ้น 4 คนและแย่ลง 2 คนก็ได้ จึงต้องดูจำนวนดีขึ้น/แย่ลงใต้กราฟและรายชื่อประกอบ

กราฟเป็น 0% หรือไม่มีแท่งสี

  • 0/20 คน (0%): มีข้อมูลเปรียบเทียบได้ 20 คน แต่ไม่มีค่าที่ตรง AlertValue
  • 0/0 หรือไม่มีคู่ที่เปรียบเทียบได้: ยังไม่มีข้อมูลที่ใช้สรุปข้อนั้น ไม่ควรตีความว่าไม่มีความเสี่ยง
  • ไม่มี AlertValue: โปรแกรมยังไม่สรุปเสี่ยง/ไม่เสี่ยงสำหรับข้อนั้น
  • อยากเห็นว่าตอบอะไรแม้เสี่ยงเป็น 0%: เปลี่ยนเป็นโหมดคำตอบทุกรหัสสำหรับรายการที่รองรับ

12. เหตุใดบางคนจึงเปรียบเทียบไม่ได้

สาเหตุวิธีตรวจสอบ
ตรวจครั้งเดียวหรือขาดรอบที่เลือกตรวจประวัติใน Records และเลือกคู่รอบให้เหมาะ
CID ต่างกันทั้งที่เป็นเด็กคนเดิมตรวจรหัสต้นทาง ไม่รวมคนโดยเดาจากชื่ออย่างเดียว
มีรอบซ้ำ หรือวันที่ตรวจผิดในประวัติตรวจทุกครั้งของเด็กคนนั้นผ่าน Records
ปลายทางเป็นวันเดียวกันหรือก่อนต้นทางตรวจวันที่และลำดับคู่รอบ
ข้อมูลว่าง รหัสผิด หรือรหัสไม่ทราบตรวจค่าที่บันทึกจริง ไม่เติม 0 เพียงเพื่อให้กราฟครบ
ข้ามกลุ่มอายุต่ำกว่า 3 ปีไปตั้งแต่ 3 ปีคะแนน/ระดับและปัจจัยคำนวณไม่เทียบข้ามเกณฑ์ แต่พฤติกรรมที่นิยามตรงกันยังเทียบได้
ข้อเกณฑ์ไม่ใช้ในกลุ่มอายุนั้นเลือกกลุ่มที่เกี่ยวข้องและตรวจคำอธิบายเกณฑ์
AlertValue ไม่พร้อมใช้ให้ผู้ดูแลตรวจ Codebook

รหัส 9 ของสถานะฟัน Debris และคำถามปัญหาช่องปากที่รองรับรหัสไม่ทราบ จะไม่ถูกนับเป็นคำตอบที่ดี ไม่ควรเปลี่ยนรหัสดังกล่าวโดยไม่มีข้อมูลตรวจรองรับ

คะแนนและระดับย้อนหลังเป็นค่าที่บันทึกไว้ ส่วนการจัดสถานะรายข้ออ่าน AlertValue จากฐานข้อมูลที่เปิด หากมีการแก้เกณฑ์ระหว่างโครงการ ควรให้ผู้ดูแลตรวจความสอดคล้องก่อนรวมผล เพราะรุ่นนี้ยังไม่ได้เก็บเวอร์ชันเกณฑ์ย้อนหลังแยกในแต่ละ Record

13. นำผลวิเคราะห์ไปวางแผนแก้ปัญหา

ใช้ตารางต่อไปนี้เป็นแนวทางประชุมทีม ไม่ใช่ฟังก์ชันบันทึกแผนภายในโปรแกรม

สิ่งที่พบสิ่งที่ควรตรวจต่อแนวทางติดตาม
กลุ่มแย่ลงเพิ่มขึ้นคลิกดูรายชื่อและข้อที่เปลี่ยนเป็นเสี่ยงวางแผนติดตามเด็กกลุ่มนี้ก่อน
พฤติกรรมเดิมยังเสี่ยงหลายรอบดูทั้งจำนวนและร้อยละ รวมค่าก่อน–หลังเลือกประเด็นสื่อสารหรือกิจกรรมที่ตรงกับพฤติกรรม
คะแนนเฉลี่ยลดแต่ระดับยังสูงตรวจรายคนและการลดคะแนนในระดับเดิมติดตามต่อโดยไม่สรุปว่าหมดความเสี่ยง
ร้อยละดูดี แต่ติดตามได้จำนวนน้อยดูเด็กที่ขาดรอบและจำนวนตัดออกเพิ่มการติดตามให้ครบก่อนสรุปทั้งโรงเรียน
หลายข้อเปรียบเทียบไม่ได้ตรวจข้อมูลและนิยามเกณฑ์แก้คุณภาพข้อมูลก่อนตีความผล

ข้อความ “พฤติกรรมที่ยังเสี่ยงทั้งสองครั้งมากที่สุด” ช่วยชี้ประเด็นเริ่มต้น โดยรุ่นนี้เลือกจากจำนวนคนที่ยังเสี่ยงในหมวดพฤติกรรมที่โปรแกรมกำหนด ไม่ใช่การจัดอันดับความสำคัญทางคลินิก และไม่ได้ปรับอันดับตามร้อยละอย่างเดียว

แนะนำให้ดูทั้งจำนวนเด็กที่ต้องดูแลและร้อยละ เพราะปัญหาที่มีจำนวนมากอาจต้องใช้ทรัพยากรมาก ขณะที่ร้อยละสูงในกลุ่มเล็กอาจบอกปัญหาเฉพาะกลุ่ม

14. ตัวอย่างขั้นตอนทำรายงานหนึ่งรอบงาน

  • 1. ระบุคำถาม: ต้องการดูพฤติกรรมดูแลช่องปากจากรอบ 1 ไป 3 ของโรงเรียน ก
  • 2. เปิดกราฟ เลือกรอบ 1 → 3 โรงเรียน ก และกลุ่มอายุที่ต้องการ
  • 3. จดจำนวนเด็กทั้งสองรอบ จำนวนที่เทียบระดับได้ และ n ของตัวชี้วัดที่จะรายงาน
  • 4. เลือกหมวดพฤติกรรม ดูโหมดคำตอบทุกรหัสแล้วสลับดูร้อยละที่เสี่ยง
  • 5. เลือกประเด็นที่ยังเสี่ยงมากหรือแย่ลง กดดูรายชื่อและค่าก่อน–หลัง
  • 6. ตรวจข้อมูลผิดปกติผ่าน Records และเปิด Dashboard ใหม่หลังแก้ไข
  • 7. บันทึกข้อสรุปและแผนติดตามในรายงานของหน่วยงาน
  • 8. รอบถัดไปใช้คู่เปรียบเทียบและนิยามตัวชี้วัดที่ชัดเจน แล้วรายงานจำนวนที่ติดตามได้ใหม่อีกครั้ง

ตัวอย่างข้อความรายงาน: “เด็กที่เปรียบเทียบพฤติกรรมข้อนี้ได้ทั้งรอบ 1 และ 3 จำนวน 20 คน มีค่าเสี่ยงลดจาก 8 คน (40%) เป็น 6 คน (30%) ลดลง 10 จุดร้อยละ โดยดีขึ้น 4 คน แย่ลง 2 คน คงผลดี 10 คน และยังเสี่ยง 4 คน ทีมจะติดตามกลุ่มยังเสี่ยงและแย่ลงต่อ”

ตัวอย่างนี้รายงานเฉพาะเด็กที่ติดตามได้ ไม่สรุปแทนเด็กทุกคนในโรงเรียน และผลก่อน–หลังไม่ได้พิสูจน์ว่าการตรวจเป็นสาเหตุของการเปลี่ยนแปลง

15. ส่งออกข้อมูลประกอบรายงาน

รุ่นปัจจุบันส่งออก Excel จากหน้า Records ได้ แต่ยังไม่มีปุ่มส่งออกกราฟหรือตารางสถิติ Dashboard โดยตรง

  • 1. กลับหน้าหลัก กด “ดูเด็กทั้งหมด (Records)”
  • 2. เลือกโรงเรียน รอบ และคลิกขวาที่หัวคอลัมน์เพื่อกรองค่าที่ต้องการ
  • 3. ตรวจแถบกำลังกรองและจำนวนรายการ แล้วกด “ส่งออก Excel (รายการที่กรอง)”
  • 4. ใช้ชื่อไฟล์ใหม่และจัดเก็บในพื้นที่ของหน่วยงาน

ไฟล์นี้เป็นข้อมูลดิบเฉพาะแถวที่แสดง ไม่ใช่ตารางคู่เปรียบเทียบของ Dashboard อัตโนมัติ และไม่ใช่ฐานข้อมูลสำรองครบทุก Sheet หากต้องการนำไปคำนวณคู่ก่อน–หลังต่อ ต้องจับคู่ CID และรอบ พร้อมตรวจเงื่อนไขการเปรียบเทียบอีกครั้ง

16. ตรวจความครบถ้วนก่อนนำเสนอ

  • 1. ระบุฐานข้อมูล โรงเรียน คู่รอบ และกลุ่มอายุที่ใช้
  • 2. ระบุจำนวนเด็กที่เปรียบเทียบได้ของแต่ละตัวชี้วัด ไม่ใช้จำนวนทั้งหมดแทนตัวหาร
  • 3. แยกไม่มีข้อมูลออกจากไม่มีความเสี่ยง
  • 4. ใช้คำว่า “จุดร้อยละ” สำหรับผลต่างร้อยละในกราฟ
  • 5. อ่านดีขึ้นและแย่ลงทั้งสองทิศทาง พร้อมเปิดดูรายคนที่ต้องติดตาม
  • 6. ตรวจว่ามีการข้ามเกณฑ์อายุหรือแก้เกณฑ์ระหว่างรอบหรือไม่
  • 7. รายงานข้อจำกัดเรื่องเด็กที่ขาดการติดตาม และไม่อ้างเหตุ–ผลเกินข้อมูล
  • 8. ใช้รายชื่อเฉพาะผู้รับผิดชอบติดตามเด็ก ส่วนรายงานภาพรวมใช้ข้อมูลสรุปตามความเหมาะสม

17. วิเคราะห์จากฐานข้อมูล .xlsm

ตั้งแต่รุ่น 1.0.1 เลือก .xlsm เป็นแหล่งข้อมูลแล้วใช้ Dashboard และกราฟได้ด้วยขั้นตอนเดิม ไม่ต้องแปลงเป็น .xlsx และไม่ต้องรัน Macro เพื่อเปิด Dashboard

  • 1. ตรวจว่าไฟล์เดิมมีโครงสร้างที่แอปรองรับและเลือกพาธถูกต้อง
  • 2. หากเพิ่งกรอกด้วย Macro ให้บันทึกและปิด Excel ก่อน แล้วเปิดฐานข้อมูลในแอปใหม่
  • 3. ตรวจข้อมูล Records โดยเฉพาะ CID รอบ วันที่ คะแนน และระดับความเสี่ยงที่ Macro บันทึกไว้
  • 4. เปิด Dashboard แล้วเลือกคู่ตรวจตามต้องการ ข้อมูลยังไม่บันทึกหรือผลสูตรที่ยังไม่มีค่าพร้อมอ่านจะไม่ถูกคำนวณแทนโดย Dashboard
