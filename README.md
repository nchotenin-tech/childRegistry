# ทะเบียนสุขภาพช่องปากนักเรียน

แอป Desktop ภาษาไทย ใช้ Python 3.12, PySide6, openpyxl และ Pydantic 2 เก็บข้อมูลใน Excel ของเครื่อง

## เริ่มใช้งาน

1. สำหรับผู้ใช้ Windows x64: ติดตั้ง `ChildRegistry-Setup-1.0.0.exe` แล้วเปิด ChildRegistry จาก Start Menu ไม่ต้องติดตั้ง Python
2. เปิดครั้งแรกจะสร้างฐานข้อมูลว่าง `Documents/ChildRegistry/studentRegistry.xlsx` เฉพาะเมื่อยังไม่มีไฟล์ และจำแหล่งข้อมูลไว้
3. กด **ตั้งค่าแหล่งข้อมูล** เมื่อต้องการใช้ฐานข้อมูล Excel อื่น โปรแกรมจะจำตัวเลือกครั้งถัดไป
4. กรอกข้อมูลทั้งหมดในหน้าเดียวแบบเลื่อนได้: แบบสัมภาษณ์อยู่ซ้าย แผนผังฟันและผลประเมินอยู่ขวา พิมพ์รหัสใน textbox แล้วกด **Enter** หรือ **Tab** ไปช่องถัดไป รหัสฟันตัวเล็กจะเปลี่ยนเป็นตัวใหญ่ให้อัตโนมัติ ค่าผิดขึ้นกรอบแดงพร้อมข้อความใต้ช่อง และบันทึกไม่ได้จนแก้ครบ ผลประเมินคำนวณอัตโนมัติเมื่อข้อมูลครบ จากนั้นกด **บันทึกข้อมูล**
5. กด **แสดงรายการ / ค้นหา** เพื่อเปิดแถบค้นหาชื่อ/CID/โรงเรียน เลือกรอบตรวจและกดโหลดเพื่อแก้ไขรายการเดิม ใช้รายการใหม่สำหรับรอบใหม่

โปรแกรมไม่บันทึกทับ Template ต้นฉบับจากหน้าจอ บันทึกตามชื่อฟิลด์แถว 3 ของ Records และเริ่มข้อมูลแถว 4 ทุกครั้งจะสร้างสำเนาก่อนบันทึกในโฟลเดอร์ `backups` ข้างฐานข้อมูล และแทนที่ไฟล์หลังเขียนสำเร็จ หากต้องคืนข้อมูล ให้ปิดโปรแกรมและนำสำเนาที่ต้องการมาเปิดเป็นฐานข้อมูล

ปิดไฟล์ฐานข้อมูลใน Excel ก่อนบันทึก หากไฟล์เปลี่ยนจากภายนอก โปรแกรมจะไม่บันทึกทับ ให้เปิดฐานข้อมูลใหม่และโหลดรายการอีกครั้ง ไฟล์ `.xlsx.lock` ใช้ป้องกันการบันทึกพร้อมกัน หากโปรแกรมถูกปิดผิดปกติ ให้ตรวจว่าไม่มีโปรแกรมอื่นใช้ฐานข้อมูลก่อนลบไฟล์ lock ที่ค้าง

## กติกาที่ใช้

- CID: ตัวเลข 13 หลัก ไม่ขึ้นต้น 00 ตามคู่มือ ไม่บังคับ checksum เพราะรองรับรหัสนักเรียน
- หน้าจอรับวันที่ DD-MM-YYYY ปี พ.ศ. ใส่ขีดให้อัตโนมัติเมื่อพิมพ์ตัวเลข 8 หลัก เช่น 12032563 เป็น 12-03-2563; เก็บเป็นวันที่จริงใน Excel และแปลงข้อมูลเดิมเป็น พ.ศ. เมื่อโหลด
- อายุเป็นปีเต็มและเศษเดือน ณ วันตรวจ น้ำหนัก >10 กก. ส่วนสูง >70 ซม.
- Codebook ฉบับนี้ไม่มี NotBlank จึงกำหนดให้กรอกทุกช่องนำเข้า ยกเว้นหมายเหตุพัฒนาการเมื่อปกติ ไม่เติมคำตอบ 0 หรือสถานะฟันปกติให้เอง
- ใช้ `cid + round_id` เป็นคีย์ ต้องโหลดรายการก่อนแก้ไข ห้ามเปลี่ยนคีย์ระหว่างแก้ไข
- อ่านคะแนนใช่/ไม่ใช่จาก G/H และตัวเลือกกลุ่มอายุจาก C/D ในตารางRiskScore ชื่อ/ตำแหน่งตารางต้องคงโครงสร้างเดียวกับ Template
- ต่ำกว่า 3 ปีใช้กลุ่มแรก ตั้งแต่ 3 ปีขึ้นไปใช้กลุ่มสอง รวมเด็กอายุ 6 ปีขึ้นไปตามผู้ใช้ยืนยัน
- r_ohplaque: พบคราบ=3 ไม่พบ=0 ตามผู้ใช้ยืนยัน แทนข้อความหัวคอลัมน์ที่ขัดกันใน Template โดยไม่แก้หัวต้นฉบับ
- Debris Index 1–3 ถือว่าพบคราบ, 0 ไม่พบ, 9 ไม่ประเมิน; เด็กต่ำกว่า 3 ปีที่ทุกซี่เป็น 9 จะไม่สามารถประเมินได้
- Visible plaque ใช้ผลตรวจที่ผู้ใช้กรอกแยกในกลุ่มอายุ ≥3 ปี
- 0–2 ต่ำ (เขียว), 3–5 สูง (เหลือง), ≥6 สูงมาก (แดง); ขีดบนของสองกลุ่มแรกอ่านจากข้อความ F27/F28
- สีพื้นทั้งแถวตามความเสี่ยง จากนั้นเซลล์ที่ตรง AlertValue เป็นสีแดง รองรับค่าเดียว หลายค่าคั่น comma และ >, >=, <, <=; r_ohplaque ใช้ AlertValue 3 ตามคำยืนยัน

## รหัสฟันจากภาพที่ผู้ใช้ให้

| รหัส | ความหมาย |
|---|---|
| A | ปกติ |
| H | ขาวขุ่นหรือเปลี่ยนสีน้ำตาล |
| N | เคลือบฟันแตกหรือมีเงาจากเนื้อฟัน |
| B | ผุเป็นรูถึงเนื้อฟัน |
| C | อุดแล้วมีฟันผุ |
| D | อุดไม่มีผุ / ครอบสเตนเลส |
| E | ฟันหายเพราะฟันผุ |
| F | เคลือบหลุมร่องฟัน |
| G | หลักสะพาน / ครอบพิเศษ / วีเนียร์ |
| T | บาดเจ็บ / แตกหัก |
| 9 | หายจากสาเหตุอื่น / ยังไม่ขึ้น / ไม่ได้บันทึก |

นับขาวขุ่นจาก H, ผุเป็นรูจาก B/C, อุดจาก C/D, ถอนจาก E; C นับได้ทั้งผุและอุด ปัจจัย r_caries ใช้ H/N/B/C ตาม Codebook

calc_* ที่ระบุจำนวนซี่เก็บเป็นจำนวน ไม่ใช่ boolean ตามหัว Records (Codebook บางรายการเขียนว่า 0/1 ไม่ตรงกัน) หากพบรหัส 9 จำนวนซี่ฟันในปากจะว่างและหน้าจอแสดง “ระบุไม่ได้” เพราะรหัสเดียวรวมกรณีไม่ได้ตรวจ ผลคะแนนขึ้นกับข้อมูลที่บันทึก จึงควรตรวจรหัส 9 ให้ครบก่อนใช้ผลประเมิน

หัวภาษาไทยของ Debris Index ใน Records บางคอลัมน์ไม่ตรงกับชื่อฟิลด์ โปรแกรมใช้ชื่อฟิลด์แถว 3 และ Codebook เป็นหลัก ไม่แก้ข้อมูลย้อนหลังหรือเปลี่ยนชื่อใน Template


เปิดจาก command line เพื่อดูข้อผิดพลาดได้ด้วย `.\.venv\Scripts\python.exe run.py` หรือระบุพาธไฟล์ Excel ต่อท้าย

ตรวจรหัสทันทีขณะพิมพ์ ส่วนวันที่ ตัวเลข และ CID ตรวจเมื่อออกจากช่องหรือกด Enter ช่องวันที่ใช้ปี พ.ศ. เท่านั้น และแสดงอายุปี/เศษเดือนอัตโนมัติเมื่อวันที่ครบและถูกต้อง เมื่อกดบันทึกจะตรวจซ้ำทุกช่องและเลื่อนไปช่องผิดแรก

## เติมรหัสฟันทีละแถว

ด้านขวาของฟันบนและฟันล่างมีช่องรหัสและปุ่ม **เติมช่องว่าง** แยกแถวละชุด เช่น พิมพ์ `a` แล้วกดปุ่ม จะเติม `A` เฉพาะซี่ที่ยังว่างของแถวนั้น ค่าที่กรอกแล้วจะคงเดิม รหัสผิดจะแจ้งเตือนและไม่เติมข้อมูล รองรับกด Enter ในช่องรหัสแทนการคลิกปุ่ม

ช่องเติมรหัสฟันบน/ล่างตั้งต้นเป็น A และเมื่อลบจนว่างแล้วกดเติม จะใช้ A เช่นกัน โดยคงรหัสซี่ที่มีข้อมูลแล้ว

## ตั้งค่าข้อมูลใช้ซ้ำ

เปิดฐานข้อมูลแล้วกด **ตั้งค่าข้อมูลใช้ซ้ำ** เลือกเปิด/ปิดแยกฟิลด์ รอบที่ โรงเรียน จังหวัด รพ.สต./รพ. และวันที่ตรวจ กำหนดค่าแล้วกด Save ค่าจะเติมเมื่อกด **รายการใหม่** และยังแก้เฉพาะรายได้ การเปลี่ยนค่าตั้งต้นไม่แก้รายการปัจจุบันหรือประวัติเดิม

ฟิลด์ที่เปิดใช้แสดงป้าย “ใช้ซ้ำ” บนหน้ากรอก วันที่ตรวจเป็นวันที่คงที่ที่ตั้งไว้ ต้องปรับเมื่อเปลี่ยนวันตรวจ หากไม่เปิดใช้วันที่ซ้ำ รายการใหม่ใช้วันปัจจุบันตามเดิม

เก็บค่าตั้งต้นในไฟล์ JSON ข้างฐานข้อมูล เช่น `studentRegistry.settings.json` คู่กับ `studentRegistry.xlsx` ค่าจะอยู่หลังปิด/เปิดแอปและแยกตามฐานข้อมูล เมื่อต้องย้ายฐานข้อมูลพร้อมค่าตั้งต้น ให้ย้ายสองไฟล์นี้ด้วยกัน ไม่เพิ่ม Sheet หรือแก้ Config ใน Excel

## Visible Plaque อัตโนมัติ

เมื่อ Debris Index ครบ 8 ช่องและเป็นรหัสที่ถูกต้อง จะคำนวณ Visible Plaque: พบ 1–3 อย่างน้อยหนึ่งซี่ = 1; ซี่ที่ประเมินได้ทั้งหมดเป็น 0 = 0; ไม่รวมซี่รหัส 9 และถ้าทุกซี่เป็น 9 จะเว้นว่างให้กรอกเอง ผู้ใช้พิมพ์แก้ค่าได้ เมื่อแก้เองแล้วการเปลี่ยน Debris จะไม่ทับค่า กด **ใช้ค่าอัตโนมัติ** เพื่อกลับมาคำนวณตาม Debris อีกครั้ง เมื่อโหลดรายการเดิมใช้ผลที่บันทึกไว้จนกว่าจะเลือกคำนวณใหม่

## แหล่งข้อมูลและตรวจสอบ Records

ใช้ **ตั้งค่าแหล่งข้อมูล** เลือก Excel โปรแกรมจำไฟล์ที่เลือกใน Windows user settings (`HKEY_CURRENT_USER\Software\StudentOralRegistry\Desktop`, key `data_source`) และเปิดไฟล์นี้เมื่อเริ่มโปรแกรม ไม่ต้องเลือกใหม่ทุกครั้ง หากย้ายไฟล์ ให้เลือกพาธใหม่ ปุ่มสร้างฐานข้อมูลถูกนำออกแล้ว หากยังมีเพียง Template ให้ทำสำเนาเป็นชื่อใหม่ใน File Explorer แล้วเลือกสำเนานั้น

ปุ่ม **ดูเด็กทั้งหมด (Records)** แสดงทุกคอลัมน์จากไฟล์ล่าสุด พร้อมเลขแถว Excel สีเซลล์ และค้นหาทุกคอลัมน์ เป็นหน้าอ่านอย่างเดียว ส่วนผลประเมินใช้กรอบสีม่วงและแสดงกลุ่มอายุ แยกจากช่องกรอก

## ติดตามผล / Dashboard

อ่านข้อมูล Records ล่าสุดโดยไม่เขียนแก้ไฟล์ เลือกทุกโรงเรียนหรือโรงเรียน (ตามการตรวจล่าสุด) เปรียบเทียบครั้งแรกกับล่าสุดหรือครั้งก่อนกับล่าสุด โดยเรียงตามวันที่ตรวจ

แสดงจำนวนเด็ก ความครอบคลุมการตรวจ ระดับความเสี่ยงก่อน–หลังแบบตาราง 3×3 ค่าเฉลี่ย/มัธยฐานผลต่างคะแนน และสถานะรายฟิลด์จาก AlertValue คลิกช่องเพื่อดูรายชื่อเด็ก คลิกเด็กเพื่อดูประวัติคะแนนและค่าก่อน–หลังรายรายการ ช่องดีขึ้น/แย่ลง/คงผลดี/ยังเสี่ยงมีตัวหารเฉพาะข้อมูลที่เปรียบเทียบได้ และมีอัตราดีขึ้นในกลุ่มเดิมเสี่ยง/แย่ลงในกลุ่มเดิมดีแยกไว้

รหัส 9 ในสถานะฟัน Debris และคำถามปัญหาช่องปากถือว่าไม่ทราบ/ไม่ได้ตรวจ ข้อมูลว่าง รหัสผิด และ AlertValue ที่ไม่ตรงกับรหัสอนุญาตไม่ถูกนับเป็นผลดี ไม่มี AlertValue จะไม่แสดงเป็นตัวชี้วัด ปัจจัยคำนวณที่ไม่ใช้งานในกลุ่มอายุไม่นับเปรียบเทียบ `r_ohplaque` ใช้ค่าเสี่ยง 3 ตามคำยืนยัน ผู้มีรอบซ้ำหรือวันที่ผิดถูกแยกออกจากการเปรียบเทียบ

คะแนนและระดับความเสี่ยงเป็นค่าที่บันทึกไว้ ไม่คำนวณย้อนหลังใหม่ ผู้ข้ามเกณฑ์อายุ 3 ปีไม่รวมการเปรียบเทียบคะแนน/ระดับ แต่ยังเปรียบเทียบคำตอบพฤติกรรมที่มีนิยามเดียวกันได้ เวอร์ชันเกณฑ์ย้อนหลังไม่ได้เก็บใน Records จึงยังตรวจความต่างของเกณฑ์ในกลุ่มอายุเดียวกันข้ามการแก้ตารางคะแนนไม่ได้

ผลแสดงความสัมพันธ์ก่อน–หลัง ไม่ใช่หลักฐานว่าการตรวจเป็นสาเหตุของการดีขึ้น ค่ารหัสใช้แสดงประกอบสถานะ ไม่ใช่สเกลที่นำมาลบกันได้ทุกฟิลด์ ขณะนี้รองรับการเลือกคู่แบบแรก–ล่าสุดและก่อน–ล่าสุด ส่วนเลือกคู่เองและกราฟแผนผังฟันย้อนเวลายังไม่ได้รวม

## กราฟเปรียบเทียบรอบตรวจ

เปิด **ติดตามผล / Dashboard → กราฟเปรียบเทียบรอบตรวจ** เลือกหมายเลขรอบต้นทางและปลายทาง โรงเรียน กลุ่มอายุ ณ รอบต้นทาง และหมวดคำถามจาก fieldmapping หรือ “เกณฑ์ความเสี่ยง” กราฟใช้เด็กที่มีทั้งสองรอบเท่านั้น ไม่ใช้คนละกลุ่มมาเปรียบเทียบร้อยละ โรงเรียนอ้างอิงรอบปลายทาง

สีฟ้าเป็นรอบต้นทาง สีม่วงเป็นรอบปลายทาง แสดงร้อยละที่ตรง AlertValue พร้อมจำนวน/ตัวหารเดียวกันแต่ละคู่รายการ และผลต่างเป็น “จุดร้อยละ” มีกราฟระดับความเสี่ยงและทิศทางการเปลี่ยนแปลง ตลอดจนค่าเฉลี่ยและมัธยฐานผลต่างคะแนน กดดูรายชื่อจากกราฟรายข้อได้

แยกกลุ่มอายุต่ำกว่า 3 ปีและตั้งแต่ 3 ปีตามรอบต้นทาง ผู้ข้ามกลุ่มไม่ถูกนำมาเทียบคะแนนหรือปัจจัยคำนวณ แต่คำตอบพฤติกรรมที่มีนิยามตรงกันยังเปรียบเทียบได้ ไม่มี AlertValue หรือไม่มีคู่ที่ใช้ได้จะไม่สร้างกราฟเสี่ยงเทียม รายการที่รอบปลายทางมีวันที่ไม่หลังต้นทางไม่ถูกนำมาเปรียบเทียบ

Dashboard เพิ่มไอคอนขึ้น/ลง/คงผลดี/คำเตือน คู่กับข้อความและสี เพื่อไม่ต้องตีความจากสีเพียงอย่างเดียว

## ตัวติดตั้ง Windows

ใช้ Windows 10 รุ่น 2004 ขึ้นไป หรือ Windows 11 แบบ x64 ดาวน์โหลด Setup จาก Releases แล้วติดตั้งโดยไม่ต้องมี Python เปิดคู่มือได้จาก Start Menu → ChildRegistry → User Manual

คู่มือครบ: [USER_MANUAL_TH.html](USER_MANUAL_TH.html) หรือ [USER_MANUAL_TH.md](USER_MANUAL_TH.md)

สำหรับผู้พัฒนา: ติดตั้ง requirements-lock.txt แล้วรัน packaging/build.ps1 บน Windows โดยมี Inno Setup ตาม workflow ตัว build มีการทดสอบเปิด exe และไม่นำ ICU ของ Poppler มารวมกับ Qt

คู่มือแยกด้านการติดตามและวิเคราะห์: [DASHBOARD_MANUAL_TH.md](DASHBOARD_MANUAL_TH.md) และ [ฉบับเปิดอ่าน/พิมพ์](DASHBOARD_MANUAL_TH.html)
