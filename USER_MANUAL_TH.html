โปรแกรมทะเบียนสุขภาพช่องปากนักเรียน

ฉบับปรับปรุง 30 กันยายน 2569 • สำหรับ ChildRegistry 1.0.1

ตัวติดตั้ง ChildRegistry สำหรับ Windows 10 รุ่น 2004 ขึ้นไป / Windows 11 แบบ x64: ใช้วิธีติดตั้งในข้อ 2.2 ได้โดยไม่ต้องติดตั้ง Python ส่วนข้อ 2.1 สำหรับผู้ที่ใช้ชุดซอร์สโปรแกรม

1. รู้จักโปรแกรมและไฟล์ข้อมูล

โปรแกรมใช้บันทึกข้อมูลเด็ก ผลตรวจฟัน แบบสัมภาษณ์ และประเมินความเสี่ยงฟันผุ พร้อมติดตามการเปลี่ยนแปลงระหว่างรอบตรวจ ข้อมูลเก็บในไฟล์ Excel บนเครื่อง

คู่มือนี้ใช้กับแอปชุดฟันน้ำนมที่พัฒนาอยู่ในปัจจุบัน ไม่ใช่แอปฟันแท้สำหรับเด็กอายุ 6–12 ปีซึ่งมีคำถามและเกณฑ์อีกชุดหนึ่ง ควรให้ผู้ดูแลยืนยันว่าแอปและ Template ตรงกับกลุ่มเด็กก่อนเริ่มงาน

ไฟล์ใช้ทำอะไร
templateRegistry.xlsxแม่แบบว่างสำหรับสร้างฐานข้อมูล ไม่ใช่ไฟล์บันทึกงานประจำ
studentRegistry.xlsx หรือไฟล์เดิม .xlsmฐานข้อมูลที่ใช้บันทึกจริง สามารถใช้ชื่ออื่นได้เมื่อเลือกผ่านตั้งค่าแหล่งข้อมูล
studentRegistry.settings.jsonเก็บค่าที่ใช้ซ้ำของฐานข้อมูลนั้น เช่น โรงเรียนและวันที่ตรวจ
backupsโฟลเดอร์สำรองฐานข้อมูลก่อนการเขียนบันทึกหรือลบ
Records-export.xlsxตัวอย่างชื่อไฟล์ส่งออกรายการที่กรองไว้ สำหรับตรวจสอบหรือจัดทำรายงาน

แม่แบบที่แจกพร้อมแอปมี Entry, Records, Codebook, ตารางRiskScore, fieldmapping และ Config ส่วนไฟล์ .xlsm ตัวอย่างเดิมมี 5 Sheet และไม่มี Config ก็ใช้งานได้เมื่อ schema ตรงกัน อย่าลบหรือเปลี่ยนชื่อ Sheet ที่มีอยู่หรือย้ายหัวตารางเอง ข้อมูลตรวจใน Records เริ่มแถว 4 โดยแถว 1–3 เป็นหัวตาราง

2. ติดตั้งและเปิดโปรแกรม

2.1 วิธีเปิดจากซอร์สโปรแกรม (สำหรับผู้ที่ไม่ได้ใช้ Setup)

  • 1. รับโฟลเดอร์โปรแกรมฉบับล่าสุดจากผู้ดูแล และแตกไฟล์ ZIP ก่อนใช้งานถ้าได้รับเป็น ZIP
  • 2. ให้ผู้ดูแลติดตั้ง Python 3.12 บน Windows
  • 3. ดับเบิลคลิก setup.bat ในโฟลเดอร์โปรแกรม ครั้งแรกต้องเชื่อมต่ออินเทอร์เน็ตเพื่อดาวน์โหลดส่วนประกอบ
  • 4. รอจนขึ้น “Setup complete. Open run.bat to start.” แล้วปิดหน้าต่างติดตั้ง
  • 5. ดับเบิลคลิก run.bat เพื่อเปิดโปรแกรม ครั้งถัดไปเปิดด้วยไฟล์นี้ได้เลย ไม่ต้องรัน setup.bat ซ้ำทุกวัน
  • 6. หากขึ้น “Setup failed” ให้แจ้งผู้ดูแลพร้อมข้อความผิดพลาด

2.2 วิธีติดตั้งด้วย Setup (แนะนำสำหรับผู้ใช้ทั่วไป)

  • 1. รับไฟล์ ChildRegistry-Setup-1.0.1.exe หรือรุ่นใหม่กว่าจากผู้ดูแลโครงการ
  • 2. ดับเบิลคลิกไฟล์ แล้วทำตามหน้าต่างติดตั้ง เลือกสร้างทางลัด Desktop หากต้องการ
  • 3. เมื่อติดตั้งเสร็จ เปิด ChildRegistry จาก Start Menu หรือทางลัด
  • 4. วิธีนี้ไม่ต้องติดตั้ง Python หรือ Git ในเครื่องผู้ใช้

ตัวติดตั้งถูกออกแบบให้ติดตั้งเฉพาะบัญชี Windows ที่ใช้งานอยู่ ใน LocalAppData/Programs/ChildRegistry หาก Windows หรือระบบของหน่วยงานไม่อนุญาตให้เปิดไฟล์ ให้ส่งข้อความแจ้งเตือนให้ผู้ดูแลตรวจสอบ

3. เปิดครั้งแรกและตั้งค่าแหล่งข้อมูล

  • 1. เมื่อยังไม่มีแหล่งข้อมูลที่เคยเลือก โปรแกรมจะสร้างไฟล์ว่างใน Documents/ChildRegistry/studentRegistry.xlsx หากไฟล์ชื่อนี้ยังไม่มี
  • 2. ตรวจพาธไฟล์ที่แสดงด้านบนหน้าหลักทุกครั้งก่อนเริ่มงาน
  • 3. ถ้ามีฐานข้อมูลเดิม ให้กด “ตั้งค่าแหล่งข้อมูล” แล้วเลือกไฟล์ .xlsx หรือ .xlsm ที่ต้องการ โดยไม่ต้องแปลงไฟล์
  • 4. โปรแกรมจะจำไฟล์ที่เลือกและเปิดไฟล์นั้นในครั้งถัดไป
  • 5. หากย้ายหรือเปลี่ยนชื่อฐานข้อมูล ให้เลือกตำแหน่งใหม่ผ่านปุ่มเดิม

ไม่จำเป็นต้องเปิด Microsoft Excel ค้างไว้ขณะใช้โปรแกรม และควรปิดไฟล์ฐานข้อมูลใน Excel ก่อนบันทึกหรือลบข้อมูลในแอป

4. ตั้งค่าข้อมูลที่ใช้ซ้ำก่อนเริ่มตรวจ

ใช้เมื่อเด็กหลายคนมีข้อมูลร่วมกัน เช่น โรงเรียนเดียวกันหรือวันตรวจเดียวกัน

  • 1. กด “ตั้งค่าข้อมูลใช้ซ้ำ”
  • 2. เปิดใช้เฉพาะช่องที่ต้องการ: รอบที่ โรงเรียน จังหวัด รพ.สต./รพ. และวันที่ตรวจ
  • 3. ป้อนค่าที่ต้องการ แล้วกด Save
  • 4. กด “รายการใหม่” เพื่อเริ่มใช้ค่าที่ตั้งไว้ ช่องที่เปิดใช้จะมีป้าย “ใช้ซ้ำ”
  • 5. ยังสามารถแก้ค่าของเด็กแต่ละคนได้โดยไม่ต้องเปลี่ยนค่าตั้งต้น

การเปลี่ยนค่าตั้งต้นไม่แก้ข้อมูลประวัติหรือรายการที่กำลังกรอกอยู่ วันที่ตรวจที่ตั้งให้ใช้ซ้ำเป็นวันที่คงที่ ต้องเปลี่ยนเมื่อเริ่มตรวจวันใหม่ หากไม่ได้เปิดใช้วันที่ซ้ำ รายการใหม่ใช้วันที่ปัจจุบัน

5. บันทึกข้อมูลเด็กและรอบตรวจ

5.1 เริ่มรายการ

  • 1. กด “รายการใหม่” และตรวจโรงเรียน รอบตรวจ และวันที่ตรวจที่เติมให้อัตโนมัติ
  • 2. ป้อนชื่อเด็กและ CID/รหัสนักเรียน โดยใช้รหัสเดิมทุกครั้งสำหรับเด็กคนเดิม
  • 3. ป้อนข้อมูลทั่วไปและคำตอบตามรหัสที่ระบุข้างคำถาม กด Enter หรือ Tab เพื่อไปช่องถัดไป
  • 4. เลื่อนหน้าจอลงเพื่อกรอกหมวดที่เหลือ ไม่ต้องเปลี่ยนแท็บ

หนึ่งรายการหมายถึงเด็กหนึ่งคนในการตรวจหนึ่งรอบ โปรแกรมใช้ CID ร่วมกับรอบตรวจระบุรายการ การตรวจครั้งใหม่ของเด็กเดิมต้องใช้ CID เดิมและรอบใหม่ ส่วนการแก้ข้อมูลรอบเดิมให้ใช้ Edit

CID ในรุ่นนี้ต้องเป็นตัวเลข 13 หลักและไม่ขึ้นต้นด้วย 00 หากรหัสของหน่วยงานไม่ตรงเงื่อนไข ให้ปรึกษาผู้ดูแลก่อนเริ่มบันทึก

5.2 วันเกิด วันที่ตรวจ และอายุ

  • ป้อนวันเกิดและวันที่ตรวจเป็น DD-MM-YYYY โดยใช้ปี พ.ศ. เช่น 12-03-2563
  • พิมพ์ตัวเลขติดกันได้ เช่น 12032563 โปรแกรมจะจัดขีดให้เมื่อป้อนครบ/ออกจากช่อง
  • เมื่อทั้งสองวันที่ถูกต้อง โปรแกรมคำนวณอายุปีเต็มและเศษเดือน ณ วันตรวจให้
  • หน้าดูรายการแสดงวันที่เป็น YYYY-MM-DD ปี ค.ศ. โดยไม่มีเวลา เช่น 2020-03-12 จึงอาจเห็นปีต่างจากหน้าป้อนข้อมูล

5.3 ตรวจฟันบนและฟันล่าง

ป้อนรหัสลงช่องใต้หมายเลขซี่ฟันตามผลตรวจจริง ตัวอักษรเล็กจะเปลี่ยนเป็นตัวใหญ่

รหัสความหมายในโปรแกรม
Aปกติ
Hขาวขุ่นหรือเปลี่ยนสีน้ำตาล
Nเคลือบฟันแตกหรือมีเงาจากเนื้อฟัน
Bผุเป็นรูถึงเนื้อฟัน
Cอุดแล้วมีฟันผุ
Dอุดไม่มีผุ / ครอบสเตนเลส
Eฟันหายเพราะฟันผุ
Fเคลือบหลุมร่องฟัน
Gหลักสะพาน / ครอบพิเศษ / วีเนียร์
Tบาดเจ็บ / แตกหัก
9หายจากสาเหตุอื่น / ยังไม่ขึ้น / ไม่ได้บันทึก

ด้านขวาของฟันแต่ละแถวมีช่องรหัสและปุ่ม “เติมช่องว่าง” ค่าเริ่มต้นคือ A กดแล้วเติมเฉพาะช่องที่ยังว่างในแถวนั้น ไม่ทับซี่ที่กรอกแล้ว เช่น กรอกซี่ผิดปกติก่อน แล้วเติม A สำหรับซี่ที่ตรวจแล้วว่าปกติ

รหัส 9 รวมหลายความหมายไว้ด้วยกัน หากมีรหัสนี้จำนวนฟันในปากอาจแสดง “ระบุไม่ได้” จึงควรตรวจความครบถ้วนก่อนใช้ผลสรุป

5.4 Debris Index และ Visible Plaque

รหัส Debrisความหมาย
0ไม่มีคราบเศษอาหาร
1มีคราบน้อยกว่า 1/3 ของผิวฟัน
2มีคราบ 1/3 ถึง 2/3 ของผิวฟัน
3มีคราบมากกว่า 2/3 ของผิวฟัน
9ไม่ได้บันทึก

กรอก Debris ให้ครบ 8 ช่อง หรือใช้ช่องรหัสและปุ่มเติมด้านขวา ซึ่งมีค่าเริ่มต้น 0 โดยเติมเฉพาะช่องว่าง

เมื่อกรอกครบ โปรแกรมคำนวณ Visible Plaque อัตโนมัติ: พบ Debris 1–3 อย่างน้อยหนึ่งซี่ให้ค่า 1; ซี่ที่ประเมินได้เป็น 0 ทั้งหมดให้ค่า 0; ไม่นับซี่รหัส 9 ถ้าทุกซี่เป็น 9 จะเว้นว่างให้กรอกเอง

ผู้ใช้แก้ Visible Plaque เองได้ เมื่อแก้เองแล้วโปรแกรมจะไม่ทับค่าด้วยการคำนวณจาก Debris หากต้องการกลับไปคำนวณให้กด “ใช้ค่าอัตโนมัติ” เมื่อโหลดประวัติเดิมจะใช้ค่าที่บันทึกไว้จนกว่าจะเลือกคำนวณใหม่

5.5 ตรวจผลประเมินและบันทึก

  • 1. กรอกข้อมูลนำเข้าให้ครบ ยกเว้นหมายเหตุพัฒนาการเมื่อพัฒนาการปกติ
  • 2. หากช่องขึ้นกรอบแดง ให้แก้ตามข้อความใต้ช่อง
  • 3. เมื่อข้อมูลครบและถูกต้อง ผลประเมินจะคำนวณอัตโนมัติ ไม่ต้องกดปุ่มประเมิน
  • 4. ตรวจผลในส่วนผลประเมินที่แยกสีจากส่วนป้อนข้อมูล รวมทั้งกลุ่มอายุที่ใช้คำนวณ
  • 5. กด “บันทึกข้อมูล” โปรแกรมตรวจข้อมูลซ้ำก่อนเขียนลง Excel
  • 6. รอข้อความ “บันทึกเรียบร้อยแล้ว” ซึ่งระบุชื่อเด็ก รอบตรวจ และแถว Excel
  • 7. โปรแกรมเริ่มรายการใหม่และเติมค่าตั้งต้นให้ พร้อมกรอกเด็กคนถัดไป

การเห็นคะแนนบนจอยังไม่หมายความว่าบันทึกแล้ว ต้องกดบันทึกและเห็นข้อความสำเร็จก่อน

รุ่นแม่แบบปัจจุบันใช้กลุ่มต่ำกว่า 3 ปีและตั้งแต่ 3 ปีขึ้นไป สีแถวแสดงระดับความเสี่ยง: เขียว = ต่ำ, เหลือง = สูง, แดง = สูงมาก ส่วนเซลล์สีแดงระบุค่าที่ตรง AlertValue ซึ่งเป็นค่าเสี่ยงของรายการนั้น

6. ตรวจสอบ แก้ไข และลบรายการ

  • 1. กด “ดูเด็กทั้งหมด (Records)” เพื่ออ่านรายการจากฐานข้อมูลล่าสุด
  • 2. ตรวจหัวตารางสามแถว หมายเลขแถว Excel และค่าที่บันทึก หัวภาษาไทยอ้างอิง fieldmapping
  • 3. กด Edit แถวที่ต้องการ โปรแกรมกลับไปหน้าป้อนข้อมูลในโหมดแก้ไข
  • 4. แก้ข้อมูลแล้วกด “บันทึกข้อมูล” ห้ามเปลี่ยน CID หรือรอบตรวจขณะแก้ไข
  • 5. หากต้องการลบ กด Delete ตรวจชื่อ CID และรอบในคำยืนยัน แล้วเลือก Yes เพื่อลบ หรือ No เพื่อยกเลิก

การลบลบเฉพาะรอบที่เลือก ไม่ได้ลบประวัติทุกครั้งของเด็กคนนั้น และมีการสำรองไฟล์ก่อนลบ หากกำลังกรอกข้อมูลค้างอยู่ โปรแกรมอาจถามว่าจะละทิ้งการแก้ไขหรือไม่

7. ค้นหาและกรองหลายคอลัมน์

  • 1. เลือกโรงเรียนและรอบตรวจจากช่องด้านบน จะใช้ร่วมกันได้
  • 2. ใช้ช่องค้นหาเพื่อค้นคำในทุกคอลัมน์ เช่น ชื่อ CID หรือชื่อโรงเรียน
  • 3. คลิกขวาที่หัวคอลัมน์ที่ต้องการกรอง กล่องกรองจะแสดงชื่อหัวข้อภาษาไทย
  • 4. ติ๊กค่าที่ต้องการ จะเลือกหลายค่าในคอลัมน์เดียวกันก็ได้ แล้วกด OK
  • 5. ทำซ้ำกับคอลัมน์อื่นเพื่อเพิ่มเงื่อนไข โปรแกรมแสดงเฉพาะแถวที่ผ่านทุกตัวกรองพร้อมกัน
  • 6. อ่านแถบ “กำลังกรอง” เหนือตาราง เพื่อตรวจคอลัมน์และค่าที่เลือกอยู่ พร้อมจำนวนรายการที่แสดง
  • 7. กด “ล้างตัวกรอง” เพื่อคืนโรงเรียน รอบ คำค้น และตัวกรองคอลัมน์ทั้งหมด

ตัวอย่าง: เลือกโรงเรียน ก → รอบ 2 → กรองระดับความเสี่ยงเป็นเสี่ยงสูงมาก จะเห็นเฉพาะเด็กที่ตรงทั้งสามเงื่อนไข หากไม่เลือกค่าใดในกล่องกรอง จะไม่มีรายการผ่านคอลัมน์นั้น

8. ส่งออก Excel

  • 1. กรองรายการให้ตรงกับงานที่ต้องการก่อน
  • 2. กด “ส่งออก Excel (รายการที่กรอง)”
  • 3. เลือกโฟลเดอร์และตั้งชื่อใหม่ เช่น โรงเรียนก_รอบ2.xlsx แล้วกด Save
  • 4. รอข้อความ “ส่งออกสำเร็จ” และตรวจจำนวนรอบตรวจที่ส่งออก

ไฟล์ส่งออกมีเฉพาะแถวที่กำลังแสดง พร้อมหัวตารางสามแถวและสีเซลล์ มี Sheet Records สำหรับรายงาน ไม่ใช่ฐานข้อมูลครบชุดสำหรับนำกลับมาใช้แทนไฟล์หลัก และไม่ใช่ไฟล์สำรองเต็มรูปแบบ โปรแกรมไม่ให้ส่งออกทับฐานข้อมูลที่กำลังเปิดหรือ Template ต้นฉบับ

9. ติดตามผลรายบุคคลและ Dashboard

  • 1. กด “ติดตามผล / Dashboard”
  • 2. เลือกโรงเรียนที่ต้องการ หรือทุกโรงเรียน
  • 3. เลือกคู่เปรียบเทียบครั้งแรก–ล่าสุด หรือครั้งก่อน–ล่าสุด ซึ่งเรียงตามวันที่ตรวจ
  • 4. ดูจำนวนเด็ก ความครอบคลุมการตรวจ การเปลี่ยนระดับความเสี่ยง และผลต่างคะแนน
  • 5. คลิกส่วนที่เปิดรายชื่อได้ แล้วเลือกเด็กเพื่อดูประวัติและผลก่อน–หลังรายรายการ
สถานะการอ่านผล
ดีขึ้นเดิมตรงค่าเสี่ยง แต่ครั้งหลังไม่ตรงค่าเสี่ยง
แย่ลงเดิมไม่ตรงค่าเสี่ยง แต่ครั้งหลังตรงค่าเสี่ยง

ตัวหารใช้เฉพาะข้อมูลที่เปรียบเทียบได้ในแต่ละรายการ จึงอาจไม่เท่ากับจำนวนเด็กทั้งหมด ข้อมูลว่าง รหัสไม่ทราบ และค่าผิดไม่ถือเป็นผลดี

10. กราฟเปรียบเทียบรอบตรวจ

  • 1. จาก Dashboard เปิด “กราฟเปรียบเทียบรอบตรวจ”
  • 2. เลือกรอบต้นทางและปลายทาง เช่น รอบ 1 เทียบรอบ 3
  • 3. เลือกโรงเรียน กลุ่มอายุ และหมวดแบบสอบถามหรือเกณฑ์ความเสี่ยง
  • 4. เลือกดู “คำตอบทุกรหัส (พร้อมสรุปความเสี่ยง)” เมื่อต้องการเห็นสัดส่วนคำตอบทั้งหมด
  • 5. เลือก “เฉพาะร้อยละที่เสี่ยงตาม AlertValue” เมื่อต้องการเน้นค่าที่เสี่ยง
  • 6. อ่านสีฟ้าเป็นรอบต้นทาง สีม่วงเป็นรอบปลายทาง และกดดูเด็กที่นำมาเปรียบเทียบในรายการที่สนใจ

กราฟใช้เด็กกลุ่มเดิมที่มีทั้งสองรอบและวันที่ตรวจเรียงถูกต้อง โรงเรียนอ้างอิงรอบปลายทาง ส่วนกลุ่มอายุอ้างอิงรอบต้นทาง

ตัวอย่างการอ่านผล: เสี่ยง 40% เหลือ 25% หมายถึงลดลง 15 จุดร้อยละ ให้ดูจำนวนเด็กและตัวหารประกอบเสมอ หากเห็น 0/20 คน (0%) หมายถึงไม่มีคำตอบตรงค่าเสี่ยงใน 20 คน ไม่ใช่ข้อมูลหาย ลองเลือกดูคำตอบทุกรหัสเพื่อเห็นรายละเอียด

รายการที่ไม่มี AlertValue ไม่สรุปว่าเสี่ยงหรือไม่เสี่ยง เด็กที่ข้ามเกณฑ์อายุระหว่างรอบไม่รวมการเทียบคะแนนหรือปัจจัยคำนวณ แต่คำตอบพฤติกรรมที่มีนิยามเดียวกันยังเทียบได้ ผลประเมินย้อนหลังใช้ค่าที่บันทึกไว้ ไม่ได้คำนวณใหม่ทุกครั้งที่เปิดกราฟ

ใช้ผลเพื่อค้นกลุ่มเด็กและพฤติกรรมที่ควรติดตาม เช่น เด็กที่ยังเสี่ยงในเรื่องเดิมหลายรอบ การเปลี่ยนแปลงก่อน–หลังเพียงอย่างเดียวไม่ได้ยืนยันว่าการตรวจเป็นสาเหตุของผลที่ดีขึ้น

11. สำรอง ย้ายเครื่อง และกู้คืน

สำรองข้อมูล

โปรแกรมสร้างสำเนาก่อนบันทึกหรือลบในโฟลเดอร์ backups ข้างฐานข้อมูล ควรปิดโปรแกรมแล้วสำเนาฐานข้อมูลล่าสุด ไฟล์ .settings.json และโฟลเดอร์ backups ไปยังพื้นที่สำรองที่หน่วยงานกำหนดด้วย

ย้ายไปเครื่องใหม่

  • 1. ปิดแอปและ Excel ก่อนคัดลอก
  • 2. นำไฟล์ฐานข้อมูล .xlsx หรือ .xlsm และไฟล์ .settings.json ชื่อคู่กันไปด้วย หากต้องการเก็บค่าที่ใช้ซ้ำ
  • 3. นำ backups ไปด้วยหากต้องการประวัติสำรอง
  • 4. ติดตั้งโปรแกรมในเครื่องใหม่ แล้วกด “ตั้งค่าแหล่งข้อมูล” เลือกฐานข้อมูลที่ย้ายมา
  • 5. ตรวจจำนวนรายการ โรงเรียน และค่าที่ใช้ซ้ำก่อนบันทึกงานใหม่

กู้คืนจากสำเนา

  • 1. ปิดโปรแกรมและ Excel และเก็บไฟล์ปัจจุบันไว้ก่อน
  • 2. เลือกสำเนาที่ต้องการจาก backups ตามวันเวลา สำเนานั้นเป็นข้อมูลก่อนการเขียนครั้งที่สร้างสำเนา
  • 3. คัดลอกออกมาเป็นชื่อใหม่ในโฟลเดอร์ใช้งาน
  • 4. เปิดโปรแกรม เลือกไฟล์ที่คัดลอกผ่าน “ตั้งค่าแหล่งข้อมูล” แล้วตรวจรายการ
  • 5. ตั้งค่าข้อมูลใช้ซ้ำใหม่หากไม่ได้ย้ายไฟล์ตั้งค่าชื่อคู่กันมาด้วย

12. ปัญหาที่พบบ่อย

อาการสิ่งที่ควรทำ
เปิด run.bat ไม่ได้ตรวจว่ารัน setup.bat สำเร็จแล้ว และยังเก็บโฟลเดอร์โปรแกรมครบ
เปิด Setup/EXE แล้วแจ้ง DLLบันทึกข้อความผิดพลาด ตรวจรุ่น Windows และแจ้งผู้ดูแลพร้อมรุ่นตัวติดตั้ง
เปิดฐานข้อมูลไม่พบกดตั้งค่าแหล่งข้อมูลแล้วเลือกไฟล์ที่ตำแหน่งปัจจุบัน
บันทึกไม่ได้ ช่องเป็นกรอบแดงอ่านข้อความใต้ช่อง แก้รหัสหรือวันที่ให้ถูก และกรอกช่องที่ขาด
ไฟล์ถูกใช้งานหรือถูกแก้จากภายนอกปิด Excel แล้วเปิดฐานข้อมูลใหม่ในแอป ตรวจข้อมูลล่าสุดก่อนแก้ไขอีกครั้ง
CID และรอบซ้ำใช้ Edit หากแก้รอบเดิม หรือเปลี่ยนรอบเมื่อเป็นการตรวจใหม่
วันที่ตรวจยังเป็นวันเก่าตรวจวันที่ในตั้งค่าข้อมูลใช้ซ้ำ แล้วเริ่มรายการใหม่
กรองแล้วไม่พบเด็กอ่านแถบกำลังกรอง หรือกดล้างตัวกรองทั้งหมด
กราฟเสี่ยงเป็น 0%ดูจำนวน/ตัวหารและโหมดคำตอบทุกรหัส อาจมีข้อมูลแต่ไม่มีคำตอบตรงค่าเสี่ยง
กราฟไม่มีคู่เปรียบเทียบตรวจ CID เดิม รอบตรวจ วันที่ และตัวกรองโรงเรียน/อายุ
มีไฟล์ .xlsx.lock หรือ .xlsm.lock ค้างให้ผู้ดูแลตรวจว่าไม่มีโปรแกรมกำลังเขียนฐานข้อมูลก่อนจัดการไฟล์ lock

เมื่อแจ้งปัญหา ให้ระบุขั้นตอนก่อนเกิดเหตุ ข้อความผิดพลาด และวิธีเปิดโปรแกรม หากส่งภาพหน้าจอให้ปิดบังข้อมูลระบุตัวเด็กที่ไม่จำเป็น

13. รายการตรวจงานประจำวัน

  • 1. ตรวจว่าเปิดฐานข้อมูลถูกไฟล์ และสำรองข้อมูลตามรอบของหน่วยงาน
  • 2. ตรวจโรงเรียน รอบตรวจ และวันที่ตรวจที่ตั้งให้ใช้ซ้ำ
  • 3. ใช้ CID เดิมเมื่อเป็นเด็กคนเดิม และรอบใหม่เมื่อเป็นการตรวจใหม่
  • 4. หลังบันทึกทุกคน รอข้อความสำเร็จก่อนเริ่มคนถัดไป
  • 5. เมื่อจบงาน เปิด Records กรองโรงเรียนและรอบเพื่อตรวจจำนวนและความครบถ้วน
  • 6. ส่งออกรายการเมื่อจำเป็น แล้วปิดโปรแกรมและสำรองฐานข้อมูลล่าสุด

คู่มือวิเคราะห์ฉบับแยก

รายละเอียดการติดตามรายบุคคล อ่านสถิติ และใช้กราฟ: คู่มือ Dashboard หรือเปิด DASHBOARD_MANUAL_TH.html เพื่ออ่านและพิมพ์

14. ใช้ฐานข้อมูลเดิมที่เป็น .xlsm

14.1 เริ่มใช้ไฟล์ที่เคยกรอกด้วย Macro

  • 1. สำรองไฟล์เดิมไว้ก่อน และใช้สำเนาในการทดลองครั้งแรก
  • 2. ปิดไฟล์นั้นใน Microsoft Excel
  • 3. เปิด ChildRegistry รุ่น 1.0.1 ขึ้นไป แล้วกด “ตั้งค่าแหล่งข้อมูล”
  • 4. เลือกไฟล์เดิม เช่น แบบบันทึกข้อมูลสุขภาพช่องปากเด็กในศพด_v2.xlsm ได้เลย ไม่เปลี่ยนชื่อเป็น .xlsx และไม่ต้อง Save As
  • 5. ตรวจพาธที่หน้าหลัก เปิด “ดูเด็กทั้งหมด (Records)” แล้วเทียบจำนวนและข้อมูลกับไฟล์เดิม
  • 6. ทดลองเพิ่มหนึ่งรายการ แก้ไข และตรวจข้อความบันทึกสำเร็จ ก่อนเริ่มใช้งานจริง
  • 7. ทดลองเปิดสำเนาที่บันทึกแล้วใน Excel เพื่อตรวจปุ่มและ Macro ตามงานที่เคยทำ

การทดสอบไฟล์ตัวอย่างผ่านการเพิ่ม แก้ไข ลบ และตรวจว่า VBA/ส่วนประกอบอื่นนอก Records และรูปแบบเซลล์เหมือนต้นฉบับทุกไบต์แล้ว แต่ยังไม่ได้ทดสอบกดรัน Macro ภายใน Excel จริง จึงควรตรวจการทำงานของ Macro บนสำเนาก่อนใช้ไฟล์จริง

ไฟล์อื่นที่นามสกุล .xlsm ไม่ได้หมายความว่าจะใช้ได้ทั้งหมด ต้องมี Sheet ชื่อฟิลด์ ชนิดข้อมูล และ Codebook ตรงกับแอป หากโปรแกรมแจ้งว่าโครงสร้างไม่ตรง ให้ส่งข้อความผิดพลาดให้ผู้ดูแล ห้ามเปลี่ยนหัวตารางเพื่อให้เปิดผ่านโดยยังไม่ตรวจความหมาย

14.2 สลับระหว่างแอปกับ Excel/VBA

  • แอปอ่านและบันทึก Records ได้ แต่ไม่ได้รัน VBA และไม่คำนวณสูตร Excel ทั้งเล่มแทน Excel
  • ก่อนแก้ในแอป ให้บันทึกและปิดไฟล์ใน Excel ก่อน
  • ก่อนแก้ด้วย Macro ให้บันทึกงานในแอปให้สำเร็จและปิดแอป จากนั้นเปิดไฟล์ด้วย Excel
  • หลังใช้ Macro ให้บันทึกและปิด Excel แล้วเปิดแอปใหม่เพื่ออ่านข้อมูลล่าสุด
  • อย่าใช้แอปและ Macro เขียนไฟล์เดียวกันพร้อมกัน หากไฟล์เปลี่ยนจากภายนอก แอปจะให้เปิดข้อมูลใหม่เพื่อป้องกันการเขียนทับ
  • ผลคำนวณเดิมที่เป็นสูตรใน Records ไม่ได้รับประกันว่าจะอ่านเป็นค่าคะแนนได้ ต้องให้ผู้ดูแลตรวจรูปแบบก่อน ไฟล์ตัวอย่างที่ทดสอบไม่มีสูตรใน Records

14.3 ไฟล์สำรองและข้อมูลใช้ซ้ำ

ไฟล์ฐานข้อมูล .xlsm จะสำรองเป็น .xlsm ใน backups และยังเก็บ VBA ไว้ การกู้คืนให้คัดลอกสำเนาออกมาเป็นชื่อใหม่แล้วเลือกผ่าน “ตั้งค่าแหล่งข้อมูล” ไม่เปลี่ยนนามสกุลเอง

ค่าที่ใช้ซ้ำยังเก็บข้างฐานข้อมูล เช่น registry.xlsm คู่กับ registry.settings.json หากมี registry.xlsx อยู่โฟลเดอร์เดียวกันด้วย จะใช้ชื่อไฟล์ settings เดียวกัน จึงควรใช้ชื่อฐานข้อมูลต่างกันหรือแยกโฟลเดอร์เมื่อไม่ต้องการแชร์ค่าตั้งต้น

ไฟล์ “ส่งออก Excel” จาก Records ยังคงเป็น .xlsx สำหรับรายงานเฉพาะแถวที่กรอง ไม่มี Macro และไม่ใช่ฐานข้อมูลสำรองครบเล่ม

15. อัปเดตจากรุ่น 1.0.0 เป็น 1.0.1

  • 1. บันทึกงานและปิดแอปกับ Excel
  • 2. สำรองฐานข้อมูล .xlsx/.xlsm พร้อมไฟล์ .settings.json และ backups ตามต้องการ
  • 3. ดาวน์โหลด ตัวติดตั้ง 1.0.1 แล้วติดตั้งทับตำแหน่งโปรแกรมเดิม
  • 4. เปิดโปรแกรม ตรวจพาธฐานข้อมูลที่จำไว้ หากต้องการใช้ .xlsm เดิมให้เลือกผ่าน “ตั้งค่าแหล่งข้อมูล”
  • 5. ตรวจจำนวนรายการและค่าที่ใช้ซ้ำก่อนเริ่มตรวจคนถัดไป

ตัวติดตั้งไม่รวมข้อมูลเด็ก และฐานข้อมูลแยกจากโฟลเดอร์โปรแกรม รุ่น 1.0.0 ยังไม่รองรับการบันทึก .xlsm อย่างปลอดภัย ต้องใช้ 1.0.1 ขึ้นไป

ข้อมูลที่ Macro เพิ่งบันทึกยังไม่ขึ้นบันทึกและปิด Excel แล้วเปิดแอป/ฐานข้อมูลใหม่
Macro หรือปุ่มใน Excel ทำงานไม่ตรงเดิมหยุดใช้ไฟล์จริง ทดสอบกับสำเนา และส่งรายละเอียดให้ผู้ดูแล
